# YBrowser audit follow-up — 2026-10-11

Baseline: `59d0abe21164becb2f21c2ee09c44ed6493c116d` (previous batch, CI #1383: unit tests and arm64 Debug **passed**).

The 174-file source snapshot was inventoried. Source scanning and selected Kotlin/JS/XML syntax checks do **not** prove every runtime path is defect-free.

## Confirmed findings fixed in this batch

| ID | Severity | Finding | Change |
|---|---|---|---|
| AUD-010 | High | Native download IDs used only the current millisecond, allowing collisions and the same `.part` path for simultaneous downloads | Serialize enqueue and check all existing IDs |
| AUD-011 | High | Native downloads automatically followed redirects while sending source-site Cookie, possibly disclosing it to a different origin | Manually follow at most 5 redirects, reject HTTPS downgrades/invalid URLs, forward Cookie only within the same origin |
| AUD-012 | High | Cancellation could race with a MediaStore publish and leave a cancelled file visible | Recheck control and persisted record after publishing, delete late publication |
| AUD-013 | Medium | Adblock matching traversed the entire subscription rule list for every URL/exception, scaling poorly | Replace O(rules) per request with case-normalized domain suffix membership checks |
| AUD-014 | Medium | Filter subscription fetch used unbounded `readText()`, potentially exhausting memory | Enforce 8 MiB read cap, reject invalid Content-Length, return failure without replacing old rules |
| AUD-015 | Medium | WebDAV response limits/errors were swallowed and connection creation could throw outside the request error boundary | Propagate read/size failures and connection errors through structured results |
| AUD-016 | High | An invalid imported preferences section could clear live configuration with `edit().clear()` | Prevalidate all present preference sections and types before writing imported files |

New pure-Kotlin tests cover download redirect and cookie-origin policy and blocked-host suffix matching. Both policy classes passed a local `kotlinc` smoke test.

## Still open — unverified, not a known count of confirmed defects

- **AUD-002:** Native Surface stacking, background retained WebView/GeckoView, IME/focus and accessibility need device testing.
- **AUD-003:** Large offline article libraries still require performance profiling and possible metadata indexing.
- **AUD-004:** Save/delete/refresh/cancel edge cases need Android instrumentation.
- **AUD-005:** Auto-hide browser controls and desktop tab-strip layouts need portrait, landscape, keyboard and fullscreen device checks.
- **AUD-017:** Native download resume/pause/cancel and cross-origin redirect behavior require integrated on-device tests against HTTP fixtures.
- **AUD-018:** Import restore is prevalidated but not a multi-file all-or-nothing transaction if disk I/O fails part-way; full transactional rollback is future hardening work.
