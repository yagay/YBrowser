# YBrowser source audit and remediation — 2026-10-11

Baseline: `b690017bdf4ec6fdeec5a926c09995945942a762`. Source: user-supplied `YBrowser-main.zip`, containing 174 tracked-file candidates across `app`, `browser-core`, and `ai-workspace`.

## Coverage and validation

- Inventoried all 174 extracted files: 131 Kotlin, 23 JavaScript, six XML, five Kotlin Gradle scripts and other assets/docs.
- Executed `node --check` on all 23 JavaScript files and XML parsing on all six XML files: no syntax errors found.
- Independently compiled pure Kotlin `OfflineSnapshotPolicy`, `BrowserDownloadIntegrity` and `WebAppScope` with `kotlinc`.
- Ran a Kotlin smoke harness for offline URL validation and HTTP range integrity; checks passed.
- Inspected Android manifest, GitHub Actions, and selected Java/Kotlin call chains covering renderer lifecycle, bookmarks, storage, synchronization and downloads.
- Android Gradle/SDK are absent in this container, so Debug ARM64 and Android unit tests **have not been run locally**. The push CI must run `:app:testDebugUnitTest`, `:ai-workspace:testDebugUnitTest` and `assembleDebug`.

## Confirmed defects addressed in one batch

1. **AUD-001: UI thread disk access.** `BrowserApp` error surface duplicated `ReaderOfflineRepository.contains()` during Compose recomposition. File existence now loads once per error/tab/profile/private-mode state on an IO dispatcher. `ReaderScreen` bookmark status likewise loads off-main, disabling the save button until status resolves.
2. **AUD-006: Backup restore could erase valid reader saves on invalid/partial input.** `BrowserBackupManager` now caps backup/reader bytes, validates all imported offline document IDs against URL SHA-256, rejects malformed/duplicate entries before mutation, uses `AtomicFile`, and preserves existing settings when older backups lack a section. Older backups lacking `readerFiles` no longer erase the offline library.
3. **AUD-007: WebDAV credentials and history could follow redirects.** `BrowserWebDavSync` now refuses automatic redirects for credentialed requests, caps remote response sizes, validates endpoint port, excludes HTTP 3xx from connectivity success, and surfaces backup export errors.
4. **AUD-008: Gecko session state could miss AtomicFile recovery.** `BrowserTabSessionStateStore` recognizes backup-only state and caps read size to prevent oversized loading.
5. **AUD-009: Range validation overflow/invalid transfer lengths.** `BrowserDownloadIntegrity` rejects negative sizes and end-offset overflow; unit tests added.
6. Reader export now recognizes committed AtomicFile backups instead of skipping them.

## Observations requiring device or Android SDK verification

- **AUD-002:** Retained WebView/GeckoView native Surface stacking, input focus, IME and accessibility on real OxygenOS devices.
- **AUD-003:** 500-document reader-library refresh still re-parses full snapshots on background IO. An indexed metadata store needs separate migration/performance testing.
- **AUD-004:** Delete/refresh lifecycle races warrant instrumentation.
- **AUD-005:** Auto-hide toolbar, desktop-style tabs and system insets require portrait/landscape, keyboard and fullscreen device checks.
- Native downloads, PWA, AI workspace website changes and provider-specific behavior require integration test cases; a source snapshot cannot prove their runtime behavior.
