# YBrowser Candy upstream

This independent branch imports the complete Android-capable source of
[Candy Browser](https://github.com/sk2andy/candy-browser).

Upstream baseline commit: `93f7ab522b43f26a7917ce2521cf777b0b3c4ff1`

Original source licence: MPL-2.0 (see LICENSE).
Preserve author notices and original licence when changing source.

The imported app is the Candy baseline, not a merge of YBrowser main
or Duck V2. The Android build targets arm64-v8a debug.
